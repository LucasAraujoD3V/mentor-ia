# Mentor IA

**Aprenda pensando. Evolua entendendo.**

Landing page do Mentor IA, proposta de plataforma Web que apoia alunos do ensino médio com perguntas, pistas e verificação, sem entregar a resposta pronta.

- **Site:** https://lucasaraujod3v.github.io/mentor-ia/
- **Brandbook:** https://lucasaraujod3v.github.io/mentor-ia/brandbook.html

Para abrir sem internet, baixe a pasta e abra `index.html` no navegador.
